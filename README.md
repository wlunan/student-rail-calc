# 学生火车票优惠计算器

静态单页，支持桌面与移动端，计算普速与动车学生票优惠，支持多程添加与分程计算说明。

## 使用方式

1. 打开 `index.html`（本地双击或用任意静态服务器）。
2. 默认已有一程，可点击“添加一程”增加行程，或“移除”删除。
3. 填写每程的坐席和票价：
  - 普速：填公布成人票价；若选择 **普速硬卧**，需额外填写同程硬座成人价。
  - 动车：填当日执行价（折后价）并输入当前折扣（0-1）。
4. 可开启“需要填写车次 / 起终点”以填写车次号、起点、终点；关闭则快速计算。
5. 点击“计算优惠”查看原始总价、学生优惠总价、节省金额及逐程计算过程；“重置”可清空。

## 主要功能
以下是当前计算器的主要功能概览：

- 支持多程：默认一程，可添加/删除行程（至少保留一程）。
- 坐席与价格：选择普速/动车座席，填写成人票价；普速卧铺需补硬座成人价。
- 快速/详细模式：可关闭“需要填写车次/起终点”快速计算，开启后可填车次号、起点、终点并校验。
- 计算规则：普速硬座/无座 5 折；普速卧铺 = 卧铺价 − 硬座价×0.5；动车座席取成人价 75% 与 40% 的较高值。
- 结果展示：显示各程成人价与学生价、计算过程，汇总原价总计、学生价总计、节省金额。
- 一键复制：可复制总计与分程明细文本，便于粘贴到笔记。
- 现代响应式 UI：适配桌面和移动端，暗色现代风格。

## 计算规则

- **普速车**
  - 无座/硬座：成人票 × 50%
  - 硬卧：学生票 = 卧铺成人价 − 硬座成人价 × 50%
- **动车**
  - 二等座、一等座、多功能座、动车组卧铺：学生票 = max(执行价 × 75%， 公布价 × 40%)，其中执行价 = 公布价 × 当前折扣。

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript
- 无依赖，开箱即用，移动优先的响应式设计。

## 开发提示

- 样式文件：`styles.css`
- 交互逻辑：`script.js`
- 需要扩展坐席或规则，可在 `script.js` 的 `seatOptions` 中增加对应配置和计算分支。
