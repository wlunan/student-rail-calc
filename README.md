# 学生火车票优惠计算器

本地手动计价的响应式单页应用，支持普速与动车学生票、多程汇总、计算明细、本地草稿、复制和打印。不调用票务接口，无需登录，不上传行程数据。

## 启动与构建

```bash
npm install
npm run dev
```

开发服务器默认地址为 `http://127.0.0.1:5173`。

```bash
npm test       # 运行票价规则测试
npm run build  # 类型检查并生成 dist/
npm run preview
```

部署时将 `dist/` 发布到静态网站托管服务即可。

## 使用方式

1. 选择列车与席别，填写成人票价，结果会实时更新。
2. 普速硬卧需补充同程硬座成人价。
3. 动车填写执行价后可按 75% 暂估；建议同时填写公布价，以校验 40% 最低票价规则。
4. 车次、起终点和日期为可选信息，可展开填写。
5. 可添加、复制或移除行程；全部行程完善后可复制结算单或打印为 PDF。
6. 草稿仅保存在当前浏览器，可通过“清空重算”删除。

## 计算规则

- **普速硬座 / 无座**：学生价 = 成人公布价 × 50%。
- **普速硬卧**：学生价 ≈ 硬卧总价 − 同程硬座价 × 50%。
- **动车组适用席别**：二等座、二等包座、一等座、多功能座和动车组卧铺。
  - 执行价不低于公布价 40%：`max(执行价 × 75%, 公布价 × 40%)`。
  - 执行价低于公布价 40%：学生价 = 执行价。
  - 未填公布价：仅显示执行价 × 75% 的暂估结果。

金额以整数分计算，逐程舍入后汇总。票价尾数、优惠资格及实际结算以 [12306 官方说明](https://kyfw.12306.cn/otn/gonggao/student.html) 为准。

## 代码结构

- `src/domain/`：席别配置、金额、票价规则与分享文本。
- `src/components/`：行程卡片、实时结算单和规则弹窗。
- `src/services/`：本地草稿与剪贴板兼容处理。
- `src/App.vue`：页面与多程状态。
- `src/style.css`：铁路票据风格、响应式和打印样式。
